# 🍿🎬 CineSearch - Movie Database Application

A modern, responsive, and highly dynamic **Movie Database Web Application** built using **React.js and Vite**. CineSearch provides a cinematic browsing experience with real-time global trending lists, a mixed Hollywood and Bollywood hero carousel, and instant live-search capabilities.

The project focuses on creating a seamless user interface with highly optimized API calls, responsive design, and efficient state management.

---

## ✨ Features

### 🎥 Cinematic Experience
- Browse a vast collection of:
  - 🇺🇸 Top Trending Hollywood Blockbusters
  - 🇮🇳 Top Trending Bollywood Hits
- View deep-dive movie information (cast, crew, overviews)
- Watch embedded YouTube trailers directly on the site
- Seamlessly mixed trending algorithms

### 🔍 Smart Search Integration
- Lightning-fast live search with autocomplete dropdown
- Highly optimized with debouncing (API rate-limit protection)
- One-click navigation straight from the search suggestions
- Auto-clearing search states for a clean UI

### ⭐ Watchlist Features
- Add movies to your personalized Favorites list
- View a dedicated Favorites dashboard
- Persistent storage using Local Storage (saves your data without logging in)

### 📱 Responsive Design
- Fully responsive layout tailored for:
  - Mobile 📱
  - Tablet 💻
  - Desktop 🖥️

### 🎨 User Interface
- Modern, Netflix-style dark theme UI
- Smooth CSS transitions and hover effects
- Loading skeletons for a polished waiting experience
- Component-based architecture

⚙️ Installation & Setup
# 1. Clone the repository
git clone [https://github.com/YourUsername/cinesearch.git](https://github.com/YourUsername/cinesearch.git)

# 2. Navigate into the project folder
cd cinesearch

# 3. Install the required dependencies
npm install

# 4. Create an environment variables file
# (Open the newly created .env file and add: VITE_TMDB_API_KEY=your_key)
touch .env

# 5. Start the local development server
npm run dev

# 🎯 How To Use

1. Open the CineSearch website.
2. Watch the Hero Banner automatically cycle through global trending hits.
3. Start typing in the search bar to see instant movie suggestions pop up.
4. Click on any movie poster or search suggestion to navigate to its details page.
5. Click the "Play" button to watch official trailers.
6. Add your top picks to your Favorites list for easy access later.
